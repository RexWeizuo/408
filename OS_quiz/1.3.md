### ✅ 参考答案与核心解析（供你自查）

1. **并发 vs. 并行**：
   * **单核 CPU 只能实现并发，无法实现并行**。
   * 多道程序设计在单核下属于**并发**（宏观同时运行，微观交替）。只有在多核/多处理器下才能实现并行。

2. **资源共享**：
   * **打印机**：采用**互斥共享**（一段时间内只允许一个程序使用）。否则，输出内容会交叉在一起。
   * **内存/磁盘**：属于**同时访问**。微观上交替访问（分时共享）与宏观上同时访问并不矛盾，这正是**资源共享**的巧妙之处（通过快速切换实现逻辑上的同时）。

3. **虚拟技术**：
   * 属于 **分时复用技术**（CPU 时间分片）。
   * **（修正）**：虚拟技术没有改变物理资源的**真实数量**，而是**改变了用户的感知**。用户以为自己独占了一台计算机，实际上是共享了一台。

4. **异步性原因**：
   * 根本原因：**资源竞争**（多个进程争夺 CPU 和 I/O 设备）以及**中断机制**（外部事件打断程序执行）。

5. **命令接口**：
   * 场景A：**联机控制方式**（交互式）。
   * 场景B：**脱机控制方式**（批处理/脚本式）。
   * 场景C：联机控制方式（虽然慢，但属于交互式）。

6. **系统调用**：
   * **`printf()` 不是系统调用**。
   * 关系：`printf()` 是 C 语言标准库函数，处于**用户态**。它的底层内部会调用 `write()` 这个**系统调用**，由操作系统完成实际的 I/O 操作。

7. **系统调用功能**：
   * 创建子进程：**进程管理类**（如 `fork`）。
   * 读取文件：**文件管理类**（如 `read`）。

8. **依赖关系**：
   * 如果不允许并发（串行执行），所有资源依次独占，**共享问题就不复存在**（因为没有竞争）。
   * 如果不能有效管理共享资源（如不控制打印机互斥），程序会因为死锁或资源争用而无法继续执行，**影响并发性**。
